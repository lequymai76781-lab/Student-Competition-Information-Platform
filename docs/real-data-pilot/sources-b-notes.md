# B组资料审核说明

本轮仅研究固定8个既有赛事，输出sources-b.json；未写正式数据库、未批准任何候选。来源在2026-09-27通过web搜索、打开正文采集，accessed_at为本次统一入册时刻。发布日不详保留null。

## 核查计数

- 8个赛事，30条来源，25条正文可读。
- 4条unavailable（超时、内部错误或空正文），1条blocked（工具不能访问）；这些记录全部零事实候选。
- 104个competition_fields / edition_fields候选值，全部通过现有validate_candidate_value白名单及类型检查。
- 机械创新、智能汽车、西门子杯、计算机设计共4个赛事具有2024/2025/2026中至少两个年度的已读来源。
- 两处高校报名或组织通知声称学校分类：燕山大学化工设计为一类、湖北经济学院法商学院计算机设计为A类。未取得实际政策认定原文，因此二者is_formal_recognition均为false；本组正式认定政策来源为0。
- 未找到足够的延期前后正文证据，本组没有制造延期事实。

## 重点审核样本

1. ICPC：官网历史文档区分1970年早期起源和1977年首届总决赛，因此保留历史时间线，没有把两者硬并为同一创办/首届整数。中国石油大学（北京）2019年正文明确ICPC原名ACM-ICPC，可以审核现名/曾用名候选；确切更名年份缺失，没有推断2018。
2. 计算机设计：2025官网明确2008创办；2024官方PDF规程另写2007始筹、2008首届。2024 PDF搜索索引日期与打开文本提取落款不同，且网页截图不可用，published_at保持null，待人工读PDF核对。
3. 机械创新：2025-03-21发布的第十二届通知，其常规赛实际年度为2026，并安排2027数字孪生挑战赛。month级决赛安排没有转换成伪造的具体日期。
4. 西门子杯：2025官网全国报名截止5月31日；中国地质大学（北京）校内截止5月22日12:00；合肥工业大学校内截止3月31日。三个截止都保留且范围分明。2026动态官网也明确独立的3月1日至5月31日报名期。
5. 电子设计：全国比赛2025-07-30 08:00至2025-08-02 20:00，官方报名5月31日；北京科技大学校内截止原文3月22日24:00，标准化为3月23日00:00。
6. 化工设计：全国预赛作品7月15日前提交；燕山大学校赛作品7月1日截止。后者只放university_notice.school_deadline。
7. 湖北经济学院法商学院：通知正文的本校A类声称仅保留为线索，不作为政策认定；页首发布日期2025-03-31、正文落款2025-05-31、校内截止4月18日不一致。未“纠正”来源，保留页首日、原截止和疑点。
8. 长江师范学院及合肥工业大学存在网页发布日期与正文落款不同，分别在来源备注中保留。

## 范围及精度

- 日精度截止与比赛日期按契约记录当日00:00:00+08:00；这只是数据精度归一化，不声称原文给出了零点。
- 月、旬、拟定区间在备注中标明。结构设计年初拟定10月15日至19日有后续赛后正文交叉确认；未把发布时的拟定表述冒充最终安排。
- 校内报名或作品截止均仅写入university_notice.school_deadline。校赛人数、校赛时间、地区规则未混入全国赛通用字段。
- 全国组委会在赛事专站发布的文件按organizer_notice记录；普通高校转载附件按university_notice记录。
- 每个来源只转述可读正文中的事实，未采集联系人个人电话号码和邮箱。
