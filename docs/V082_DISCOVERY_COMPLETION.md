# V0.8.2 高校竞赛发现链路收尾记录

日期：2026-09-13（Asia/Shanghai）

## 结论

本轮完成了专校公共入口、入口优先级、正向赛事信号过滤、官方 PDF 文本解析和回归计数修正，但三校 Recall 门槛仍未达成，因此 V0.8.2 不能标记为完成。不得用当前发现到的其他真实赛事替代既定真值，也不得把搜索结果页当成来源。

## 现有三段链路

1. 入口发现：官网首页、robots/sitemap、公开子站、有限 known path、站内搜索及搜索引擎 `site:` 结果。
2. 候选发现：从栏目与分页提取官方域内文章或 PDF；搜索引擎只提供入口。
3. 验证与关联：校验官方域名、近期窗口、赛事正向信号与通知类型；只有报名、校内选拔、作品提交等可执行通知才可建立 edition 关系。

## 华中农业大学 trace

- 入口：主站 -> 本科生院；专校 registry -> 信息学院通知公告、外国语学院通知公告、经济管理学院。
- 成功：导航、known path、department feed；专校入口设为最高入口优先级，避免被普通首页栏目截断。
- 有效发现示例：校计算机设计大赛、农业机器人创新大赛、生物信息设计与技能竞赛、中国国际大学生创新大赛校赛公示等。
- 过滤：创新班遴选、智慧课程建设、普通培养项目不再因“没有负类词”而进入 Lead。
- FN：市场调查与分析大赛、“外研社·国才杯”四新专项赛等历史页面未进入有限分页候选集。

## 武汉理工大学 trace

- 入口：主站，以及交通与物流工程学院教学公告、船海与能源动力工程学院通知公告、新闻经纬等公开子站。
- 失败：主站/多个子站持续 HTTP 403；部分入口 HTTP 502，交通学院 HTTP 降级超时。
- 合法 fallback：robots/sitemap、公开二级域名、学院栏目、站内/搜索引擎入口发现、官方 PDF 解析。不会无限重试、伪装绕过或把搜索结果页落为来源。
- 本轮结果：23 次抓取仅 1 次成功，16 次明确 403，目标通知仍为 FN 3；状态应为 `completed_with_gaps/source_unavailable`，不能假称稳定完成。

## 高校关系语义

- `recognition`：学校正式竞赛目录或明确认定文件支持。
- `notification`：学校或学院发布过该赛事通知，只能证明通知关系。
- `participation`：参赛、获奖、活动报道，只能证明参与事实。

现有关系字段可分别承载 recognition status、notice URL/校内时间和 participation status，本轮不做数据库迁移。获奖新闻不得提升为学校认可。
