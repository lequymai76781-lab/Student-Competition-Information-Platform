## 21. 数据质量问题

- 11 个选定赛事仍只有线索材料；不能把目录标题转换为确定字段。

## 22. 后台操作痛点与本轮修复

已验证赛事、学校、来源、状态、风险/冲突与时间筛选，以及分页返回不同记录。没有为了本轮重做后台。记录以下限制：来源核验仍按字段操作；学校关系没有正式批准操作；多个原文和失败重试需切换任务状态；冲突筛选成本高；真实管理员吞吐未知。

实际修复：不同来源零字段材料错误折叠、普通队列全量构建详情、学校材料误走赛事字段整理、租约失效旧进程覆盖新检查点、仅改来源展示 key 造成重复、公开 jobs 暴露内部来源/路径、重试丢失前次失败记录、日期精度被显示成虚假的 08:00。每项以失败复现/断言后修复，保留日志。独立代码复查指出的租约/去重/隐私问题已复验通过；没有沿用“代理完成”代替主流程回归。
