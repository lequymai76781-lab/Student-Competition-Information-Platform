## 16. 发现的数据模型与接入边界

1. 当前字段审核实体只覆盖 Competition/Edition；学校映射、认定政策仍作为待整理证据，没有直接学校关系批准动作。本轮保留原始材料并阻止错误认定，未声称学校关系审核链路已补齐。
2. 同赛事同年可能有多个阶段/专项。现有单一届次截止不应承载NCDA专项、蓝桥不同赛项的多组截止；这些范围值保留原始证据。
3. datetime 无独立“仅日期/精确到分钟/暂定”的精度字段。日精度候选按README约定00:00存储并注明，审批时须阅读备注；月份区间未转换成虚构具体日。
4. 长期主办方与当届组委会缺少同一字段内的范围表达，智能汽车例子交由人工判断；未自动覆盖。
5. 限定代码复查还发现共享 stage 在 `fields={}, raw=None` 的多来源幂等边界：摘要不含独立来源时可能复用候选。本轮导入始终在 raw 保存完整 source，不触发；其他接入脚本扩量前应补此边界。未顺手改造所有旧采集入口。

以上限制使当前方案适合有人工复核的受控候选扩量，尚不适合无人工干预的全面自动入库。
