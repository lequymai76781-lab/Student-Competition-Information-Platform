## 正式认定政策

南京邮电大学校教发〔2025〕1 号 PDF 是正式认定目录，不是赛事组织报名通知。存于 `a-njupt-recognition-policy-2025`（数模样本），`source_type=university_policy`、`notice_type=policy_recognition`、`is_formal_recognition=true`，有 `recognition_evidence`。它支持本校数模 A 类，但全局字段对象保持空。

同一文件还列出：创新/两项挑战杯为 A 类，大广赛/三创/市调为 B 类，NCDA 为 C 类。政策只在南京邮电大学适用，不能推广为全国通用等级。

## 留空和限制

- 未因高校获奖新闻、报名通知或主办方自己的“认定”宣传，自动建立正式高校认定。
- 市调中国商业统计学会官方获奖 PDF 打开失败，只留线索，未复制搜索摘要事实进入字段。
- 没有从既有数据库取值补缺，没有替换正式赛事名称或批准候选。
