## 检索与保真方法

使用 web 搜索定位，再打开来源正文/PDF；搜索摘要只作线索。可读PDF按照实际文本提取，不把零行PDF或未查看到图像的截图当成已读取正文。网页正文日期优先于URL迁移路径日期；动态首页混排新闻时不编造发布日期。字段保持小量、原子化，不从口号推导荣誉等级或自动验证状态。

父任务已将自由文本失败原因保存为 source_failure_detail，并将 source_failure_reason 规范化为现有枚举；原失败诊断不丢失。本研究不再覆盖父任务规范化后的JSON。
